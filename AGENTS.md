# Repository instructions

This is a public-candidate local-host writing demo.

- Keep the manuscript as continuous prose. Do not add chat bubbles, avatar turns, group chat, or message timelines.
- A Book is the isolation boundary. Never inject characters, world rules, canon, summaries, or manuscript text from another Book.
- Author and character modes share one persistence, context-plan, provider, and apply pipeline. Character mode only narrows authority and viewpoint.
- Prompt visualization shows provider input material and inclusion reasons, never hidden model reasoning.
- Use neutral synthetic fixtures. Do not add private story text, people, accounts, device names, local usernames, network addresses, endpoints, credentials, or deployment details.
- Keep secrets outside story files and browser storage. The demo has no real Provider. The Sites build keeps Book data only in device-local browser storage; do not add manuscript cloud persistence or seed it with private local stories.
- Prefer Node standard library, native HTML controls, plain CSS, and the smallest focused test that proves non-trivial behavior.
- Preserve existing changes. Run `npm test`, `npm run typecheck`, and `npm run build` before claiming completion.
- Local commits use `Bénie Studio <321945707+beniedev@users.noreply.github.com>`. Do not create a remote, push, release, or choose a license without maintainer approval.
