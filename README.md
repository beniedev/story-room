# Story Room

Story Room 是一个轻量的本地优先写作空间：用来写故事、随手保存笔记，也可以在需要时请 AI 帮忙。

从一个场景、一个角色或几行想接着写的文字开始。书稿始终以连续正文呈现。每本书稿都有独立的角色、世界设定、提纲和章节；每次生成前，你可以选择要带入的材料。你可以用作者身份写作，也可以从角色的第一人称视角写作；还可以比较不同的续写候选，保留最适合故事的一版。

你的故事始终保存在本地：在电脑运行应用时保存为可读文件，在浏览器模式下保存在浏览器中。AI 请求会把你选入上下文的写作材料发送给你配置的模型服务；Story Room 不提供云端书稿存储或自动同步。

这是 Alpha 早期版本。欢迎试用、探索并反馈。项目持续完善期间，请为重要的写作内容保留独立备份。

## 开始使用

你需要 Node.js 22.18+ 或 24，以及 npm。在项目目录中运行：

```bash
npm ci
npm run dev
```

打开 `http://127.0.0.1:4310`。选择示例书稿或新建书稿，打开一个小节，然后开始写作。内置示例服务（Fake）可以先用示例输出体验完整写作流程，再连接 AI 服务。要使用自己的模型，请在设置中添加 OpenAI 兼容的模型服务。

界面目前为中文。[中文使用手册](docs/USER_GUIDE.zh-CN.md) 会按界面原文说明按钮；[英文使用手册](docs/USER_GUIDE.md) 也提供按钮对照表。若你正在使用 AI 助手，[中文智能体指南](docs/AGENT_GUIDE.zh-CN.md) 说明功能、代码入口和维护流程；对应的[英文智能体指南](docs/AGENT_GUIDE.md) 也会保持同步。

## 你的故事保存在哪里

| 运行方式 | 书稿保存位置 | AI 支持 |
| --- | --- | --- |
| 电脑上的本地服务模式 | `.data/` 下的可读文件；可用 `STORY_DATA_DIR` 指定其他目录 | 示例服务或你配置的 OpenAI 兼容模型服务 |
| 浏览器中的浏览器模式 | 属于当前浏览器和网站来源（协议、主机和端口）、未加密的 `localStorage` | 仅支持示例生成；连接测试可以访问你配置的 `/models` 端点 |

你可以随时带走一份副本。EPUB、Markdown 和 TXT 导出包含你选择的书稿正文。需要同时保留备选答案、分支、书稿设置、上下文选择和**小节梗概**时，请使用**完整 JSON**备份；如果存在上一份快照，它也会包含在内。从书架导入这个 JSON 会恢复一本新书稿，不会覆盖已有书稿。

浏览器中的书稿属于当前浏览器和网站来源（协议、主机和端口）。清除站点数据会删除它们。清除数据或换浏览器前请先导出；浏览器模式不会上传或合并你的书稿。

### 从其他设备打开本地服务

默认绑定地址是 `127.0.0.1`。如果要让受信任局域网或私有网络中的其他设备访问同一个本地服务，请显式选择绑定地址，例如 `npm run dev -- --host 0.0.0.0`。应用不会额外添加访问密码、访问令牌或主机名白名单；任何能访问所选地址的设备都可以使用它。带有 `Origin` 请求头、会改变状态的浏览器请求必须保持同源。

已配置的模型服务可以在公网、回环地址、局域网或私有网络地址上使用 HTTP 或 HTTPS，不需要额外的启用标志。元数据目标、链路本地目标和重定向仍会被拒绝，以免把凭据发送给非预期服务。

### 在本机试用网页发布版

想先体验带示例书的网页版本，可以运行：

```bash
npm run build
npm run preview
```

打开终端显示的地址，默认是 `http://localhost:4327`。这会在本机预览用于云端发布的同一套构建和网页运行方式：示例书与修改保存在当前浏览器中，续写使用示例生成，不需要配置密钥。它不会启动本地文件书库服务，也不会发布到云端；停止预览时按 Ctrl+C。

## 连接 AI 服务

在本地服务模式下，你选择模型服务和模型。应用会把上下文方案中包含的写作材料发送给该服务，因此请选择你信任的端点。模型选择会记住在当前浏览器中。连接设置和 API 密钥保存在本地服务一侧，与书稿分开。

<details>
<summary>连接、密钥和连接测试的工作方式</summary>

本地服务支持确定性的示例服务和 OpenAI 兼容端点。生成请求所需的上下文方案和提示词由应用内部组装，然后发送到用户配置的模型服务端点。`/api/context-plan` 返回紧凑的预览；`/api/generate` 返回草稿以及用于比较答案的来源签名元数据，不会回显内部消息。写作界面不会显示原始模型服务消息。本地服务模式的 API 密钥默认以明文保存在 `.data/private/providers.json`；可设置 `STORY_PROVIDER_CONFIG` 选择其他文件。在 POSIX 系统上，该文件以 `0600` 模式写入。Windows 文件权限不会被视为等价的凭据存储。修改已保存配置的 `endpoint` 或 `kind` 时，需要重新输入密钥。

在浏览器模式下，生成仍使用示例生成。模型服务测试会把临时密钥发送到配置的 `/models` 端点；页面脚本在页面运行期间可以读取这个输入，但应用不会持久化该密钥。测试成功只能证明端点有响应；如果端点返回模型列表，还能证明配置的模型 ID 存在。它不能证明 `/chat/completions` 接受本应用的生成参数。

</details>

## 可以先试试这些

- 在每本书稿中把角色卡、世界规则和章节放在一起。
- 先亲自写一段，再请求续写或另一个答案。
- 比较答案候选，把想要的版本放进书稿。
- 打开上下文抽屉，查看这次会带入哪些写作材料以及原因。
- 调整主题和字体，或在接近手机宽度的窗口中使用界面。
- 导出阅读版或完整 JSON 备份。

### 保存和保护草稿

修改会自动保存。如果应用发现你正在基于较旧的保存版本继续工作，它会保留本地修改，并让你选择导出或重新加载；不会替你合并互相冲突的编辑。

<details>
<summary>本地服务模式的保存与恢复细节</summary>

每次更新仍会保存并校验整个书稿（Book）。客户端发送它加载版本的 `updatedAt` 值，本地服务会在串行保存队列中比较这个值。如果另一个页面先保存，旧版本请求会被 HTTP 409 拒绝，不会覆盖较新的书稿。页面会保留本地修改和答案候选，停止后续的旧版本自动保存，并提供 JSON 导出或明确的重新加载；它不会自动合并。

发布本地服务模式的保存前，存储层会记录私有事务日志，并为之前管理的书稿文件和书目索引建立快照。进程内保存失败会立即回滚。删除书稿使用同一个恢复区域：完整的书稿目录树先移入已准备好的事务，书目更新发布后，删除才会提交并进行物理清理。重启后，未提交的保存或删除会回滚；已提交的事务会保留或完成，清理也会安全重试。读取、保存、导入和删除共用同一个进程内队列，因此普通请求不会看到存储处于恢复的中间状态。这能保护事务一致性，但不能防止磁盘丢失，也不能协调两个独立的本地服务进程共享同一数据目录；重要内容仍需要外部备份。

</details>

### 打开多个浏览器标签页

浏览器模式在每个浏览器存储区域和网站来源中只允许一个编辑页。受支持的浏览器在安全上下文（HTTPS 或受信任的 localhost）中会使用 Web Locks API 自动选出这个编辑页。其他标签页保持只读页：可以浏览已保存的书稿、查看上下文、导出已保存内容和修改显示偏好。它们不会读取编辑页的恢复草稿。其他标签页发生修改时，当前页面会显示重新加载操作，不会在你阅读时替换文字。

如果要把编辑权移到只读页，请关闭之前的编辑页，然后选择“尝试成为编辑页”。新的编辑页会先重新加载已保存的书目和书稿，再检查恢复草稿并启用编辑。系统不会后台重试，也不会强制接管。如果 Web Locks 不可用、页面不是安全上下文，或锁初始化失败，已保存的书稿仍可读取和导出，但浏览器模式的编辑会保持禁用。请使用受支持的浏览器和安全 URL，或使用上面的本地服务模式；本地服务模式的编辑不依赖 Web Locks。

`updatedAt` 和草稿的 `baseUpdatedAt` 检查仍是防止旧版本保存和恢复草稿冲突的第二层保护。这个锁只协调同一网站来源上运行当前版本的标签页；升级后请关闭旧标签页。它不会协调不同网站来源、浏览器配置、设备或独立的本地服务。浏览器事件和 `localStorage` 不是协作或持久化系统；冲突仍需通过导出或重新加载恢复。

### 尝试另一个续写

使用“再生成一版”尝试另一个答案，再用箭头浏览候选。选择某个候选会更新书稿并保存你的选择。如果所选模型配置已经被删除，应用会选择一个可用配置。

<details>
<summary>生成使用哪些文字，以及候选会保留多久</summary>

编辑已经发送过的用户段落后，可以在它的答案上使用“再生成一版”，从该答案之前最新采用的文字生成新的候选。这次请求会排除旧答案、它的其他候选以及后续段落。如果书稿最后是用户段落，段落下方的“生成回答”会生成答案，不会重复用户段落，也不会消耗底部输入框中的下一份草稿。

候选箭头会立即切换当前书稿版本，并在后台保存选择；它们不会启动生成。当前显示答案的编辑、删除和“再生成一版”操作仍作用于该答案。生成另一个候选时，它会自动成为当前候选。后续生成、普通导出、统计和小节梗概的新鲜度都使用当前版本。在小节中间切换答案会保留后面的段落，可能需要检查上下文连贯性。

候选会在刷新后继续保留，直到下一次新输入得到并成功保存答案。此时，只保留前一个答案的当前版本，删除它的其他候选。失败或取消会保留这些选择。重新生成答案，或不输入新内容直接继续，都不会清除候选。完整 JSON 备份会包含书稿中仍然存在的候选。

候选来源签名记录写作材料的变化，但不会再保存一份完整提示词快照。已有书稿无需批量迁移仍可读取，候选数量也没有应用定义的上限。

</details>

设置中的“流式输出”默认关闭，并记住在当前浏览器中。启用后，书稿生成会逐步显示收到的文字。完整结果沿用非流式答案的书稿和候选保存流程。如果生成被取消或失败，部分文字仍可在页面上选择和复制，但不会保存进书稿。开始另一次生成会替换这份临时预览，重新加载页面会清除它。小节梗概生成仍会等待完整的结构化结果。浏览器模式仍使用示例生成。

<details>
<summary>本地 API 客户端的流式格式</summary>

`POST /api/generate` 接受可选的布尔值 `stream`。流式响应使用 `application/x-ndjson`，先发送包含 `text` 的 `delta` 事件，随后发送包含普通生成结果的 `result` 事件，或发送 `error` 事件。只有最后的 `result` 表示生成完成；连接中断不算完成的答案。不使用流式传输的请求仍返回 JSON 格式。

</details>

### 给模型提供合适的上下文

写作页的上下文抽屉会显示当前模型服务的限制、近似输入预算，以及本次请求包含哪些材料和包含原因。如果请求超出预算，或材料被排除、降级，预览会明确说明。它不会显示原始模型服务消息或隐藏的模型推理。本地服务模式的模型服务仍会收到这次生成所需的内部组装消息；API 只返回应用需要的上下文预览或生成草稿。

取消生成会中止本地请求，并把中止信号传递给模型服务请求。生成没有应用定义的截止时间；作者可以在等待时取消。迟到的结果不能写入书稿或小节梗概，取消也不会清除作者当前的输入或笔记。但这无法撤回已经被配置端点接受的工作，也无法删除该端点的日志。

书稿级提纲（`plotOutline`，界面中的“剧情大纲”）会作为后续指导，放入普通续写和整块重新生成的提示词。小节的 `note` 会作为写作页显示的当前小节提示，放入该小节的非摘要提示词；其他小节的注释不会带入。旧版小节 `plan` 数据仍可读取和导出，但不会插入模型服务提示词。书稿摘要和既定事实同样是保存并可导出的书稿数据，不是隐藏的提示词来源。在“前文选择”中，勾选框会加载或移除较早的小节，其余行会展开行内梗概编辑器。小节梗概是一个五字段的结构化摘要，可以从模型草稿或手动草稿开始；生成梗概只会修改本地草稿，直到你确认保存并加载。当前小节梗概及其上一份快照会与书稿一起持久化，并包含在完整 JSON 导出中。

模型生成的小节梗概在确认前不会插入普通续写。浏览器模式的生成仍使用示例生成，也没有自动云端存储或同步。模型服务的密钥和端点仍是信任边界：只有在信任当前页面和目标 URL 时，才输入临时设备测试密钥；本地服务模式的密钥按上文所述保存。

## 这个 Alpha 版本的预期

- API 请求、模型服务响应和小节梗概没有应用定义的大小或条目数上限。保存仍会传输并校验整个书稿。对同一未变化版本的保存会复用结果，本地服务也会跳过内容相同的来源文件和正文文件的重写。大型书稿仍需要更多内存和 I/O。未来的小节/来源修订 API 见[英文的增量保存设计](docs/INCREMENTAL_SAVE.md)；该 API 尚未实现。
- 上下文估算仅供参考，不会阻止生成。模型上下文和输出设置接受正的安全整数；实际支持的限制由你配置的模型服务决定。
- 浏览器 `localStorage` 未加密，同源脚本可以读取。清除站点数据会删除设备本地书稿，设备运行时也不提供文件系统级事务恢复。
- 本地服务和模型服务端点都不是生产部署。浏览器、操作系统或已配置端点被攻破，不在本演示的保障范围内。
- 项目没有云端存储、账号同步、多用户协作、RAG、向量嵌入或桌面封装。

关于数据处理、恢复边界和问题报告，请参阅以下目前只有英文版的资料：[安全说明 `SECURITY.md`](SECURITY.md)、[隐私说明 `PRIVACY.md`](PRIVACY.md) 和[威胁模型 `docs/THREAT_MODEL.md`](docs/THREAT_MODEL.md)。
